Privacy Policy

Last updated: 2026-10-10

rclone-backup is a personal, non-commercial tool. Its only user is its owner.

Data accessed

With the owner's authorization, rclone-backup creates, reads, updates, and deletes only the files it has created in the owner's Google Drive. It does not access any other files.

Use of data

The files are encrypted backups of the owner's own computer, encrypted on that computer before upload. Data is used only to store and restore these backups. It is not sold, shared with third parties, or used for advertising.

Storage

Authorization tokens and the encryption password are stored only on the owner's own computer. No data is stored on other servers operated for rclone-backup.

Revoking access

Access can be revoked at any time from the Google Account "Third-party apps and services" page.
